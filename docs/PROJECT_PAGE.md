# Project homepage

The public project page is https://yihaohu0118.github.io/ViSS/.
Its buildless HTML, CSS, JavaScript, and assets live in `site/`.

The page uses figures and reported results from the accompanying manuscript.
It includes the paper PDF, controlled comparisons, setup guides, and citation.
The result tables are manuscript results, not outputs generated by the CPU tests.

To preview locally:

```bash
python -m http.server 8000 --directory site
```

Open http://localhost:8000. Pushing changes under `site/` to `main` runs the
GitHub Pages workflow. The published PDF is `site/assets/ViSS.pdf`; when the
manuscript changes, update that file and any affected figures or reported
numbers together.

Before the initial publication, the page was checked at desktop and mobile
widths, including comparison buttons, figure enlargement, clipboard actions,
local links, and the result table with JavaScript disabled. The 34-page PDF
was compiled and visually inspected; the Code and Project Homepage URLs are
clickable at the end of its abstract.
