01 / The idea

An action label does not
tell you how many times.

The same action, seen once or three times, can receive the same label. A model can learn that label without learning to count.

We call this state under-specification: histories that differ in order, accumulation, or relations share an answer, leaving those distinctions unconstrained. Visible-State Supervision (ViSS) asks for them directly, including whether the visible evidence is sufficient to answer at all.

Test-Time Causal View Search (TVS) addresses a separate limitation. With the trained model frozen, it acquires complementary views of the observed video prefix when recent frames are insufficient.

Read the full abstract +
An action seen once and the same action seen three times receive the same action-recognition label, so that supervision does not require a model to count. Answers shared across histories that differ in event order, accumulation, or relations leave those distinctions unconstrained; we call this state under-specification. Visible-State Supervision (ViSS) addresses it by training on source-grounded probes of event identity, order, accumulation, relation change, and answer sufficiency; under the same recent-frame interface it improves OVO-Bench over a strict-matched generic temporal supervision baseline while remaining comparable on StreamingBench, with the largest gain in hallucination detection. Test-Time Causal View Search (TVS) then adapts evidence access while keeping the learned model fixed, expanding from recent frames to sparse event and compact history views on demand. The two interventions separate representation from view selection: supervision particularly benefits hallucination detection and causal reasoning, access particularly benefits event recall and forward reasoning. Together they reach the best reported accuracy among the published systems compared here on StreamingBench and OVO-Bench at a fraction of the processed frames of exhaustive selection, and strict replay shows that most of the remaining gap to a three-view oracle is a correct answer that was later replaced. Streaming accuracy depends on what supervision asks the model to keep, what evidence inference exposes, and whether the model keeps a correct answer once it has one.

02 / The method

Learn the visible state.
Search the causal views.

Two controlled interventions separate representation learning from evidence access.

I

Visible-State Supervision

Train on source-grounded probes of event identity, order, accumulation, relation change, and answer sufficiency. One fresh epoch updates the language model and multimodal projector while the vision tower stays frozen.

Five probe familiesQwen3-VL-8B
II

Test-Time Causal View Search

Start with four recent frames. Acquire a sparse event view when the recent confidence margin is low; consult compact history when the proposals disagree. Separate acquisition and commitment thresholds are fixed on a source-disjoint holdout.

+1.72 OVO points

Beyond generic temporal supervision.

The mean ViSS gain over strict-matched generic supervision across three paired seeds is 1.72 OVO points (95% paired-bootstrap CI: 0.80–2.60). StreamingBench remains comparable.

17.08 frames per query

Adaptive access on StreamingBench.

TVS reaches 86.33% with 17.08 processed frames on average, compared with 86.45% and 29.97 frames for a single full-history call. TVS averages 1.60 model calls.

The remaining oracle gap is conditional on correct proposals being available. Strict replay finds that replacing an already correct answer dominates these selection errors; the calibrated commitment margin does not show a consistent aggregate benefit.
